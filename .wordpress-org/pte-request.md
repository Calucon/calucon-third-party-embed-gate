# PTE-Antrag (translate.wordpress.org)

Importierte Übersetzungen bleiben auf „waiting“, bis ein PTE (Project
Translation Editor) für dieses Projekt oder ein GTE der Sprache sie freigibt.
Plugin-Autoren bekommen diese Rechte nicht automatisch — sie werden auf Antrag
im Polyglots-Blog vergeben.

**Wo:** https://make.wordpress.org/polyglots/ (neuer Beitrag auf der Startseite)
**Format:** genau das Template aus dem Handbuch (das führende kleine „o“ wird
zur Checkbox, mit der das Team den Antrag abarbeitet).
**Wichtig:** Sprachvarianten nicht einzeln beantragen — `#de_DE` schließt
`de_DE_formal` ein. `de_AT` und `de_CH` sind eigene Locales mit eigenen GTEs
und gehören als eigene Zeilen in denselben Beitrag.

---

## Titel

    PTE Request for Calucon Third-Party Embed Gate

## Text

I am the plugin author for Calucon Third-Party Embed Gate. I have submitted
German translations for it and would like to be able to approve them, and to
keep them current as the plugin is released.

- https://wordpress.org/plugins/calucon-third-party-embed-gate/

o #de_DE – @calucon
o #de_AT – @calucon
o #de_CH – @calucon

About the translations, so you can judge them before granting anything: I am a
native German speaker and I reviewed every string myself. The first draft was
produced with AI assistance and then corrected by hand — wording, grammar and
register — against the German style guide and glossary, including the „…“
quotes, the protected space before a dash, and „und“ instead of „&“. The
formal (Sie) branch is a written pass, not a search-and-replace. The Swiss
files follow de_CH orthography (ss for ß, guillemets). The strings are already
submitted as suggestions, so they can be reviewed as they stand.

Two things I deliberately did not translate: the changelog entries, and the
plugin name itself.

If you would rather review them yourselves before granting PTE, that is
completely fine — please just tell me where to improve them.

If you have any questions, just comment here. Thank you!
